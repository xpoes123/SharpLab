How to read this

Projected = votes counted ÷ the source's "% expected vote in" (CNN, falling back to NYT/AP, then Fox). It assumes the uncounted vote looks like the counted vote, so watch for the classic traps: mail/early counted first (D-leaning early, R-leaning election-day in most states), big urban counties dumping late, and states that count for weeks (CA, WA, OR, AZ, NV, AK). ± is a rough 1σ that shrinks as more is in. Model = P(yes) from a normal around the projection; edge = model − market mid (green = model says yes is cheap). Nothing projects until 3% is in. Turnout markets settle on certified totals, which include late provisionals; the projection doesn't know about those. It's a scratchpad, not a forecast: sanity-check any edge against the county map before you size up. Refreshes every 30 s.
